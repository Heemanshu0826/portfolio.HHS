## 🚀 How to Run

### Option 1: Direct File Open
Simply double-click `index.html` in your file explorer to open it in Google Chrome, Microsoft Edge, Brave, or Firefox.

### Option 2: Local HTTP Server (e.g., VS Code Live Server or Python)
In PowerShell inside this folder:
```powershell
python -m http.server 3000
```
Then visit: `http://localhost:3000`

## 🌐 1-Click Deployment
This project is 100% static with no compilation required:
- **GitHub Pages**: Push this directory to a GitHub repository, go to `Settings -> Pages`, and choose `main` branch.
- **Vercel / Netlify**: Drag-and-drop this folder or connect your repo for instant worldwide deployment with HTTPS.
